## Approach

### Test design

Add inside the existing `Show Hidden toggle — editor project` describe block (line 205) — keeps the test grouped with the related toggle behaviour, runs **before** the viewer-project tests so cleanup is per-test (afterEach style).

Flow:

1. `openDiagram(page)` + `selectMapFromCombobox(page)`.
2. Capture initial polygon/node count and choose a target — `Domain Beta` L1 (second polygon, isolated subtree, won't cascade-hide other test data).
3. First click → focus. Second click on same node → menu opens.
4. Assert `.bcm-menu-card` visible and contains "Hide".
5. Click `text=Hide` inside the menu card.
6. Assert the L1 polygon for `Domain Beta` is no longer in DOM (use `data-node-name` selector).
7. Click `Show Hidden` toggle.
8. Assert the L1 polygon for `Domain Beta` is back (with dashed-border class, but presence is enough).
9. Cleanup: turn off `Show Hidden` so canvas is in the same state for next tests, then unhide via Apex (anonymous DML).

### Cleanup strategy

There is no UI "Unhide" action — the only way to restore `bcm_HideFromDiagram__c = false` mid-run is anonymous Apex.

```ts
test.afterEach(async () => {
    if (!hideTestRan) return; // gate: only run if Hide test ran
    const orgAlias = process.env.SF_ORG_ALIAS;
    const apex = `update [SELECT Id FROM bcm_Capability__c WHERE bcm_Map__r.Name LIKE '%${RUN_ID}%' AND bcm_HideFromDiagram__c = true].each(c => c.bcm_HideFromDiagram__c = false);`;
    // … sf apex run --file
});
```

Simpler: do the unhide inline at end of the test body itself (no `afterEach` gating), wrapped in `try/finally` so the unhide always runs even on assertion failure.

### Selector tactics

- `selectMapFromCombobox` already waits for `polygon` first child. After hide the polygon for `Domain Beta` should disappear; selector pattern: `svg.bcm-canvas g.bcm-node[data-node-level="1"][data-node-name*="Domain Beta"]`.
- `bcm_CapabilityMap.html` line 159 confirms `data-node-name={node.name}` and `data-node-level="1"` attributes are present on each L1 group.

## Risks

- **Two-click reliability:** the second click must hit the same node before any pan/drag handlers swallow it. `node.click(); node.click();` worked in existing viewer test (line 287–288), so pattern is proven.
- **Apex unhide cleanup:** if `SF_ORG_ALIAS` is unset the cleanup throws; same constraint as the existing teardown — acceptable.
- **Test order dependency:** placing this in the editor describe block means it runs before the viewer block; viewer tests must see Beta visible (they do — `selectMapFromCombobox` waits for `polygon` not specific names). Inline cleanup ensures Beta is restored before exit.
- **Show Hidden toggle state leak:** test toggles Show Hidden on and off; final state matches initial. Verified by reading `bcm_CapabilityMap.js` toggle handler (idempotent).

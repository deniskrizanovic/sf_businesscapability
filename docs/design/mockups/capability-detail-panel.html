Annotations

  1. Width / position: 400px fixed, anchored to right edge of .bcm-canvas-container; full canvas height (top:0; bottom:0). Overlay — does not push diagram.
  2. Slide-in animation: transform: translateX(100%) → translateX(0); transition: transform 250ms ease;. CSS class .bcm-detail-panel.open toggled by detailIsOpen getter on container.
  3. Header: breadcrumb (root → current, current bolded) on the left, × close button (also bound to Esc) on the right.
  4. Level badge: coloured pill at top of body, matches L1/L2/L3 colour palette used by the diagram so the user has continuity of context.
  5. Tag swatches: read-only pills with the existing tag colour. Editing tags is out of scope for this slice.
  6. Field list: Name (text), Definition / Strategy Support / Architectural Nuance (rich text via lightning-input-rich-text), Hide From Diagram (read-only display in this slice — the toggle is deferred per plan §28).
  7. Edit affordances: only rendered when canEdit is true. Footer Save/Cancel pinned to bottom; Save is disabled until isDirty.
  8. Loading state: spinner overlay covers the body, header still visible so user can close. Used while initial fetch or save in flight.
  9. Error state: red banner above fields; edit values preserved so user can retry. Same pattern for fetch error and save error.
  10. Switching nodes (not pictured): panel does not close — header breadcrumb + body re-render in place; spinner shown while new fetch is in flight.
